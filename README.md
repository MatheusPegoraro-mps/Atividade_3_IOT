Descrição da atividade

Nesta atividade, foi montado um circuito com Arduino Uno, dois LEDs e um botão. O objetivo é controlar os LEDs por meio dos cliques no botão. 
A cada pressionamento, o Arduino alterna entre LED vermelho, LED verde e ambos apagados, praticando o uso de botões, LEDs e contadores na programação.
